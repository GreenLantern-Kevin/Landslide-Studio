# M2F-DeepLab 分割推理说明

本文定义 LandslideStudio 的分割输入、权重加载和输出约定，供模型部署、结果复核与实验复现使用。基本操作见[使用指南](使用指南.md#segmentation)，平台概览见 [README](../README.md)。

## 1. 网络版本与适配范围

平台接入 [M2F-DeepLab](https://github.com/GreenLantern-Kevin/M2F-DeepLab)，固定提交为 `e655ee310f5e9dfafceb33ca2afc92f214e14c29`。推理网络定义位于 `vendor/M2F-DeepLab/network/`，来源与声明见 [UPSTREAM.md](../vendor/M2F-DeepLab/UPSTREAM.md)。平台实例化网络并执行推理，不调用训练入口。

默认使用完整 E 模型 `m2f_deeplabv3plus_xception16`，两类输出，类别 0 为背景、类别 1 为滑坡。默认关闭可分离卷积转换；输出步长未在 checkpoint 中记录时采用配置值 16。其他网络变体必须使用各自匹配的训练权重。

## 2. 权重与元数据

将训练完成的权重放入 `models/segmentation/m2f_deeplab.pth`，或通过 `segmentation.multimodal_weights` 指定路径。推荐使用保留配置元数据的完整 checkpoint，以便复现实际评估设置。

支持包含 `model_state` 或 `state_dict` 的字典，也支持纯张量参数字典。若所有参数名统一带有 `module.` 或 `_orig_mod.` 前缀，加载器会去除对应公共前缀。模型不会使用随机初始化参数替代缺失的推理权重。

### 可读取的参数

加载器依次检查 checkpoint 顶层及其 `config`、`args`、`opts`、`hparams`、`training_config` 字典，也检查这些字典中的 `segmentation` 配置。每项参数采用首个符合类型要求的记录，并保存来源。

| 有效字段 | 可识别的记录名 | 说明 |
| --- | --- | --- |
| `model_name` | `model_name`、`model` | 网络工厂名称；顶层与 `config.model` 冲突会报错 |
| `output_stride` | `output_stride` | 支持 8 或 16，必须与训练设置一致 |
| `num_classes` | `num_classes` | 当前 M2F-DeepLab 接入要求两类 |
| `separable_conv` | `separable_conv` | 布尔值，必须匹配训练网络 |
| 训练输入尺寸 | `input_size`、`crop_size` | 保留元数据，不自动当作评估缩放尺寸 |
| `eval_resize` | `eval_resize`、`val_size` | 评估缩放边长；0 表示使用原始尺寸 |
| schema | 顶层 `schema_version` | 用于识别限定的训练辅助头兼容情况 |

类别数可从已知最终分类层形状识别，明确元数据优先。输出步长、裁剪尺寸、归一化方法和通道编码无法仅凭普通卷积张量形状确定；缺少元数据时应核对训练配置。

通过页面“检查权重可识别的参数”或以下命令查看元数据：

```powershell
.venv\Scripts\python.exe scripts/inspect_weights.py models/segmentation/m2f_deeplab.pth
```

### 严格加载规则

权重始终以 `torch.load(..., weights_only=True)` 读取。读取器仅对训练指标中已知的 NumPy 数值标量提供兼容，不自动切换到任意 Python 对象反序列化。若权重包含不受支持的对象，应在可信训练环境中导出纯参数字典，并保留可用的标量配置元数据。

推理前逐项比较参数名称、缺失项、多余项和形状，然后调用 `load_state_dict(..., strict=True)`。架构不符时停止运行，不能通过关闭严格加载掩盖差异。

### schema 2 训练辅助头的有限兼容

仅在以下条件全部成立时，加载器允许在内存中排除训练辅助头：

1. 顶层 `schema_version=2`。
2. 实际模型与元数据均为 `m2f_deeplabv3plus_xception16`。
3. 元数据明确记录 `output_stride` 为 8 或 16、`num_classes=2`、`separable_conv=false`。
4. 该推理网络的全部 1674 项参数均存在，且各项形状完全匹配。
5. 仅多出下表八项 `classifier.aux_classifier.` 参数，名称和形状逐项一致。

| 参数后缀 | 形状 |
| --- | --- |
| `0.weight` | `(256, 728, 3, 3)` |
| `1.weight` | `(256,)` |
| `1.bias` | `(256,)` |
| `1.running_mean` | `(256,)` |
| `1.running_var` | `(256,)` |
| `1.num_batches_tracked` | `()` |
| `3.weight` | `(2, 256, 1, 1)` |
| `3.bias` | `(2,)` |

这些参数属于不参与当前 `seg` / `edge` 推理的训练辅助头。排除操作只作用于内存中的参数字典，随后仍执行 `strict=True`；原 checkpoint 文件不变，结果元数据会记录排除项。

此兼容规则不适用于任意多余参数、缺失层、其他辅助头形状或未知训练版本，也不构成通用的部分加载机制。

## 3. RGB 与 DEM 输入

### RGB

使用与训练预处理一致的 `uint8` RGB 影像。TIFF 至少包含三个波段，默认将前 3 个波段视为红、绿、蓝；高位深数据需要事先按训练方法转换，平台不会自动进行辐射拉伸。

### 三通道地形图

DEM 输入必须为训练流程预处理得到的三通道 `uint8` 高程/坡度/坡向地形图，保留文件解码后的通道顺序与 0–255 像素编码。当前接入使用 `dem_input=prepared_rgb`，不从原始单波段高程重新派生地形特征，也不将灰度图复制为三通道。

三通道地形图中的编码数值不能直接当作以米或角度表示的原始地形量。图像外观相似不足以说明其预处理与训练一致。

### 配准与有效区域

RGB 和 DEM 必须逐像元对应。两者具备地理参考时，检查 CRS、仿射变换及尺寸；普通图片需要尺寸一致并由使用者确认覆盖范围、方向和像元位置一致。适配器的显式重投影选项仅适用于具备地理参考的输入，默认不会将不同尺寸的图像直接拉伸成配准结果。

RGB+DEM 统计使用两者共同有效区域；RGB-only 使用 RGB 的有效区域。缺少共同有效像素时停止运行。保留有效像素掩膜以区分背景与无数据区域。

### 归一化

RGB 与地形图均先除以 255，再按通道执行 ImageNet 标准化：

```text
mean = [0.485, 0.456, 0.406]
std  = [0.229, 0.224, 0.225]
x_normalized = (x / 255 - mean) / std
```

当前 M2F-DeepLab 接入要求使用上述参数；改变地形通道编码或归一化会改变模型输入分布。

## 4. 缺失 DEM 的处理

适配器通过 `has_dem` 明确告知双流网络是否提供了 DEM，不通过图像亮度推断模态是否缺失。

| 情况 | 路径 |
| --- | --- |
| 双流模型收到地形图 | `has_dem=True`，使用真实 DEM 特征 |
| 完整 E 模型仅收到 RGB | `has_dem=False`，使用 FHM 特征补全 |
| B 变体仅收到 RGB | `has_dem=False`，使用零地形特征 |
| A 变体 | RGB 单流 |

RGB-only 能力取决于所用变体及其训练。它不意味着双流模型已经变成独立训练的 RGB 模型，也不保证与 RGB+DEM 输入具有相同精度。模型路径与 DEM 是否存在会写入结果统计。

## 5. 参数优先级与影像处理策略

默认 `auto_match_checkpoint=true`，优先使用明确记录的 checkpoint 参数；可识别的分类层形状用于补充类别数。用户可为本次任务指定输出步长、窗口尺寸和滑窗重叠。模型名称、输出步长、类别数或可分离卷积设置与已有元数据冲突时，停止推理。

### 输出步长

页面支持自动、8、16。自动模式优先采用 checkpoint 记录，缺少记录时采用配置默认值 16。手动选择不是重新训练网络，也不应根据输出外观猜测步长。

### 评估尺寸与训练裁剪尺寸

`eval_resize` / `val_size` 控制评估缩放；缺少记录时使用配置值，默认配置为 256。值为 0 时，自动模式按原始影像尺寸推理。`crop_size` / 训练 `input_size` 单独记录，不自动覆盖评估尺寸。

| 策略 | 行为 |
| --- | --- |
| `auto` | 未手动填写尺寸时，根据 `eval_resize` 决定缩放或原图推理；本次指定尺寸时使用该尺寸缩放 |
| `native` | 保持原图尺寸，不分块，忽略窗口尺寸与重叠 |
| `resize` | RGB 和地形图以双线性插值缩放为指定正方形，再推理 |
| `tiles` | 以指定窗口和重叠遍历原图，对重叠区概率加权融合 |

页面手动窗口/缩放尺寸接受 64–1024 的整数，无 16 倍数限制；滑窗重叠范围为 `0 ≤ overlap < input_size`。大图显存不足时可选择滑窗，例如窗口 256、重叠 64。

缩放模式将网络网格上的概率以最近邻恢复至原图尺寸，使默认二类阈值判别与上游的网格分类、最近邻掩膜导出约定一致。滑窗采用重叠概率融合，因此不同策略和尺寸的输出不应视为数值等价。

## 6. 输出与指标

网络 `seg` 输出经 softmax 后提取类别 1 的概率。默认阈值为 0.5，采用严格大于阈值的判别；两类概率相等时保留背景，与上游 argmax 的并列处理一致。无效像素排除在统计之外。

| 文件 | 内容与编码 |
| --- | --- |
| `input_rgb.png` | 本次使用的 RGB 图像 |
| `mask.png` | 0=背景或无效像素，255=滑坡候选 |
| `valid_mask.png` | 255=有效像素，0=无效像素 |
| `overlay.png` | 候选区域与 RGB 的叠加图 |
| `probability.npy` | `float32` 概率数组，无效像素为 NaN |
| `probability.png` | 0–255 概率预览，无效像素显示为 0 |
| `metrics.json` | 网络与版本、有效参数及来源、权重加载信息、模态路径、策略和统计 |
| `mask_geo.tif` | 有地理参考时导出；0=背景，1=滑坡，255=无效值 |

区域统计包括有效像素数、候选像素数与占比、连通斑块数量和最大斑块像素数。只有影像具有可用投影坐标和长度单位时，才由像元变换计算候选面积平方米；经纬度影像不能直接用度数换算面积。

模型概率未经校准，不能视为灾害发生概率或可靠性评分。没有真值标签时，平台不输出准确率、IoU 或 F1。

## 7. 验证范围

已使用真实训练权重验证 RGB+DEM 和 RGB-only 两条 GPU 推理路径，并核对限定 schema 2 辅助头兼容后的严格加载。该验证证明相应权重与配置可执行推理，不代表跨 checkpoint、跨硬件或跨数据集的普遍兼容性。

平台尚未提供正式精度基准。开展模型比较或区域应用前，应固定网络版本、权重、预处理、空间分辨率及推理策略，并使用独立真值数据评估结果。
